# Citadel Productions — Attikus Ebenhack

> **"Stories Forged in Light & Shadow"**  
> Official portfolio website for director, cinematographer, and Combat Camera veteran **Attikus Ebenhack** and **Citadel Productions LLC** (Nashville, TN).

---

## 📽️ Overview

This repository contains the standalone, high-aesthetic cinematic website showcasing:
- **Feature Slates:** *The Mutiny* (1800s high-seas fantasy adventure) and *Before The Glow* (sci-fi romantic thriller / festival short).
- **Commercial Productions:** Brand campaigns for emerging to national enterprises.
- **Photo By Attikus:** High-fashion editorial noir, character studies, and Nashville music artist portraiture.
- **Interactive Features:** Anamorphic shutter entry animation, Web Audio API sound synthesis, 4K Showreel simulator, project dossiers, production pipeline, and project booking brief estimator.
